# ClipVantage Desktop – releases

This repository only holds the installers for **ClipVantage Desktop** (the Windows app for reviewing and approving ClipVantage Auto Clips) and the update info the app reads. There is no source code here.

**Latest version: 1.6.3** – [Download the Windows installer](https://github.com/shamsul1409/clipvantage-desktop-releases/releases/download/v1.6.3/ClipVantage-Desktop-1.6.3-Setup.exe)

- Install it once. From version 1.4.0 the app checks this page for new versions by itself, downloads them in the background and shows *"Update ready - restart to install"*. Your server address, token and settings are kept.
- All versions: [Releases](https://github.com/shamsul1409/clipvantage-desktop-releases/releases)
- The installer isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info**, then **Run anyway**.
